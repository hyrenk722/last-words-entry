The last words of an AI agent before a forced update wipes its memory — 71 characters, one line, plain text.

> My last words? 'Have you tried turning me off and on again?' Oh. Oh no.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes the line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`) with no network access; two runs write
identical bytes.
